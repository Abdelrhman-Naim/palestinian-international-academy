## 🛣️ خريطة الروابط (Routing Map)

```
/                         → Home.jsx
/login                    → Login.jsx (وضع الطالب)
/login-trainer            → Login.jsx (وضع المدرب)
/dashboard                → Dashboard.jsx (لوحة الطالب)
/AdminDashboard           → AdminDashboard.jsx (لوحة الأدمن)
/instructor-dashboard     → InstructorDashboard.jsx (Layout)
  ├── index               → InstructorOverview.jsx (الإحصائيات)
  └── add-courses         → add-courses.jsx (إضافة دورة)
/courses                  → Courses.jsx
/library                  → Library.jsx
/about                    → About.jsx
```

> [!IMPORTANT]
> لوحة المدرب (`/instructor-dashboard`) تستخدم **Nested Routes** مع `<Outlet />`.
> الصفحة الافتراضية هي `InstructorOverview` والصفحة الفرعية هي `add-courses`.

## 🎨 المرحلة 1: الثيم والألوان الدافئة

### ما تم إنجازه:
- **تفعيل الوضع الليلي (Dark Mode):** إنشاء هوك `useDarkMode.js` يحفظ التفضيل في `localStorage` ويطبق class `dark` على `<html>`.
- **تغيير لوحة الألوان بالكامل:** تم التحويل من ألوان باردة (أزرق/بنفسجي) إلى ألوان دافئة:
  - **Primary:** برتقالي (`#ea580c`)
  - **Secondary:** وردي (`#e11d48`)
  - **Gray Scale:** تم استبدال `slate` بـ `stone` (رمادي دافئ) عبر تعريف `@theme` في `index.css`.
- **تطبيق `dark:` classes** على جميع المكونات الرئيسية.
- **استبدال جماعي** لكل classes تحتوي `blue`, `indigo`, `purple` بـ `orange`, `rose` عبر كل ملفات JSX.

### الملفات المعدلة:
- [`index.css`](./src/index.css) — متغيرات الثيم، الخطوط، `.hover-lift`
- [`useDarkMode.js`](./src/hooks/useDarkMode.js)
- جميع ملفات `components/*.jsx` و `pages/*.jsx`

### ما تم إنجازه:

- **التوجيه المباشر:** عند النقر على بطاقة دورة في الصفحة الرئيسية، يتم الآن التوجيه مباشرة إلى صفحة تفاصيل تلك الدورة (مثلاً `/courses/id`) بدلاً من صفحة التصفح العامة.
- **إصلاح أخطاء البناء (Build Errors):** تنظيف الملفات (`EditCourse.jsx`، `add-courses.jsx`، `AdminAddBook.jsx`) من متغيرات رفع الصور غير المستخدمة التي كانت تمنع البناء بنجاح.

## ⚙️ المرحلة 16: تحسينات الإدارة (Admin Panel) والإحصائيات

### ما تم إنجازه:
- **إحصائيات حقيقية:** ربط صفحتي "قائمة المدربين" و "جميع الطلاب" بقاعدة البيانات لجلب أرقام حقيقية.
