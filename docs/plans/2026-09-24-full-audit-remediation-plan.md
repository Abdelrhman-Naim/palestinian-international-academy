# Comprehensive QA, Security & UX Remediation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** معالجة وحل جميع المشكلات الـ 14 المكتشفة في الفحص الشامل (المشكلات الحرجة P0/P1، المشكلات المتوسطة P2، وتحسينات التصميم والتوطين والاستجابة) بدقة متناهية ودون أي تأثير جانبي على استقرار المنصة.

**Architecture:**
- **أداء التحميل وشبكة الخطوط:** استبدال حظر تحميل خط Material Symbols بآليات غير معطلة (Non-blocking) مع مهلة زمنية صارمة وضمان عدم تسرب نصوص الأيقونات (Ligature Leakage) أو تشوه الهيدر تحت أي ظرف للشبكة.
- **معالجة الروابط الميتة:** تفعيل كافة روابط القائمة الجانبية وصفحة الأنشطة بنوافذ ومسارات فعلية مستهدفة بدلاً من `href="#"`.
- **استقرار تدفق البيانات:** إضافة آليات حماية من التعليق اللانهائي (Safe Fallback Timeouts) لصفحة الواجبات، وتوحيد حالة حفظ الكتب عبر نظام متزامن وفوري لا يتأثر بأخطاء الخادم.
- **الإشعارات وتقدم الطالب:** تصحيح قراءة معرّف المستخدم `currentUser.id`، وتفعيل التحديث التفاؤلي الفوري عند "تحديد الكل كمقروء"، وتثبيت حفظ نسبة الإنجاز في Supabase لمنع أي تضارب بين الإشعارات والبطاقات.
- **سرعة التنقل وتجربة المستخدم:** التحميل المسبق لصفحة الرسائل لمنع تأخر الانتقال، وتوحيد احتساب أعضاء المجموعات، وتصحيح نصوص الأزرار، وتوضيح حالة المقررات المسجل بها في الكتالوج، وإصلاح خلط اللغات وتجاوب القوائم على شاشات الجوال.

**Tech Stack:** React 19, Vite, Tailwind CSS v4, Supabase (Auth, Postgres, Realtime), Framer Motion, React Router v7.
